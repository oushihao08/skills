# Skills

个人 AI Skill 集合，源自 `~/.agents/skills/`。每个目录的 `SKILL.md` 是入口，配套脚本、参考资料、素材及原有许可证随目录保存。

## 使用

将需要的 Skill 目录放入 `~/.agents/skills/`；Codex 使用 `~/.codex/skills/<名称>` 指向同名源目录的软链接。部分 Skill 含本地路径或依赖外部工具，使用前阅读其说明并按环境配置。

仓库不包含真实 `.env`、缓存、运行锁或嵌套 Git 元数据；软链接 Skill 已展开为实际文件，便于克隆后使用。
